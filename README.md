### Engineering approach

- **Build:** turn a concrete problem into a working implementation.
- **Threat-model:** identify trust boundaries, permissions, and likely abuse paths.
- **Test:** create reproducible normal-use and adversarial experiments.
- **Document:** distinguish verified results from limitations and future work.

> **Research integrity:** SYNTHSHIELD uses synthetic data and is not claimed to be production-certified. Its dashboard displays **recorded experiments**, not live SOC telemetry. See the [technical report](https://github.com/Nikhilbal/synthshield/blob/main/reports/phase12/technical_documentation.md) and [security limitations](https://github.com/Nikhilbal/synthshield/blob/main/reports/phase12/security_findings.md).
